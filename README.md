# AI New Canada

The source for [ainew.ca](https://ainew.ca), an independent Canadian AI-news publication covering models, products, business, research and policy.

## Editorial principles

- Start current-affairs reporting with a primary source.
- Separate reported fact, company claim and AI New analysis.
- Label advertising, sponsorship and affiliate relationships clearly.
- Note material factual corrections on the article.

## Local development

The project uses vinext and the Sites hosting runtime. Install dependencies, run `npm run dev`, and open the local URL printed by the development server.
